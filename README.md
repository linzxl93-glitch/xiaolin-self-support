# 晓霖的自我支持工作台 v1.1

一个可直接发布到 GitHub Pages 的纯静态网页 APP。它不需要安装依赖、构建工具、服务器或 API。

也可以直接双击打开 `index.html` 预览；本地预览和 GitHub Pages 都会显示完整月历。

## 直接发布到 GitHub Pages

1. 在 GitHub 创建一个新仓库，例如 `xiaolin-self-support`。若使用 GitHub Free，请选择“Public”。
2. 打开本文件夹，**将里面的 `index.html`、`assets`、`tests` 和说明文件上传到仓库根目录**；不要把整个文件夹再套一层上传，否则 Pages 找不到入口文件。
3. 在仓库顶部打开 **Settings** → 左侧 **Pages**。
4. 在 **Build and deployment** 的 **Source** 选择 **Deploy from a branch**。
5. 选择 `main` 分支和 `/(root)`，然后点击 **Save**。
6. 等待部署完成后，回到 **Settings** → **Pages**，点击 **Visit site** 打开固定网址。

首次发布通常需要几分钟；GitHub 官方说明最多可能需要 10 分钟。之后每次上传或推送修改，页面会自动重新发布。

## 使用说明

- 月历会在主区域固定显示完整的 7 列 × 6 行；在日历中点任意日期，就能为该日期编辑每日工作台与便利贴。未来日期可预写，过去日期可补写。
- 便利贴输入后会显示“有未保存修改”。点击 **保存便利贴** 后才会写入当前浏览器，并显示“已保存”。
- 切换日期或回到今天时，未保存便利贴会要求你留在当前日期保存，或明确确认放弃修改。
- 绿色日期表示该日有工作台记录；黄色日期表示该日有已保存便利贴；两者可同时出现。

## 重要：数据保存范围

GitHub Pages 只负责让网页有固定网址；本版本的记录仍保存在**当前设备、当前浏览器**的本地存储中。换设备、换浏览器、使用无痕模式或清除网站数据后，记录不会自动同步或恢复。请不要把私密内容上传到仓库代码或公开写进网页文件。
